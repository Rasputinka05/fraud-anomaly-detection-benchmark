# Benchmark of Unsupervised Anomaly Detection & Feature Stacking on Financial and Blockchain Fraud

Сравнительное исследование алгоритмов поиска аномалий без учителя (PyOD) на классических транзакциях кредитных карт и графовом блокчейн-датасете Elliptic Bitcoin. Реализация подхода Semi-Supervised Anomaly Feature Stacking для преодоления эффекта мимикрии аномалий.

---

## Ключевые результаты (Executive Summary)

1. CreditCard Fraud (Геометрические выбросы):
   * Модели без учителя (OCSVM, Isolation Forest, PCA Outlier, HBOS) показали устойчивое качество ROC-AUC > 0.955 без использования меток мошенничества.
   * Построен бутстрап доверительных интервалов (1000 итераций): подтверждено статистическое пересечение интервалов топовых моделей (OCSVM mean AUC 0.962 [0.905, 0.994] против Isolation Forest 0.960 [0.898, 0.993]).

2. Границы применимости на блокчейне (Elliptic Dataset):
   * В условиях отмывания криптовалют мошеннические транзакции мимикрируют под плотные связные компоненты графа, из-за чего локальные дистанционные и плотностные методы (LOF, kNN) терпят инверсию скора ($AUC < 0.50$).
   * Anomaly Stacking: Сжатие 166 признаков графа до 5 скоров аномалий разнородных детекторов позволило легкому мета-классификатору (LightGBM) достичь ROC-AUC = 0.934, показав сопоставимое качество с «тяжелым» прямым бустингом (0.980) при существенном сокращении вычислительного графа.

## Методология и стек

* Данные: 
  * *CreditCard Fraud Dataset:* 284k транзакций, PCA-трансформированные признаки, дисбаланс фрода 0.17%.
  * *Elliptic Bitcoin Dataset:* транзакции графа Биткоина (203k узлов, классифицированные сущности: licit vs illicit).
* Стек: Python, PyOD (IForest, OCSVM, HBOS, PCA, KNN), LightGBM, scikit-learn, SciPy, seaborn.
* Метрология: Оценка через стратифицированный ROC-AUC и эмпирический бутстрап метрик вместо некорректных t-тестов на разномасштабных сырых скорах моделей.

## Инженерные выводы (Production Insights)

1. Выбор архитектуры под природу данных:
   * Если фрод представляет собой редкие нетипичные выбросы по суммам и геолокациям (CreditCard) — оптимален запуск легковесных моделей Isolation Forest или HBOS без привлечения разметчиков.
   * Если мошенники применяют алгоритмы маскировки и микширования (AML в крипте) — неразмеченные методы должны использоваться строго как генераторы мета-признаков для супервайзед-моделей.
2. Эффективность стекинга: Ансамбль из быстрых линейных детекторов ($O(N)$) нивелирует квадратичную вычислительную сложность алгоритмов плотности типа LOF, делая решение масштабируемым под высокие нагрузки.
